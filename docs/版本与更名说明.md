# 版本与更名说明（CpuScore → SiliconScope；首个公开版本 V1.0.0）

> 适用：首个开源版本 **V1.0.0**。
> 两件事：① 产品英文名定为 **SiliconScope**；② 公开版本号重置为 **1.0.0**。
> 中文名「CPU 体质评分」作为中文功能描述保留。

## 1. 版本号怎么对应
- 本项目**首次公开发布即 V1.0.0**；开源前只有未发布的内部原型迭代，没有任何公开版本。
- 公开版本号从 1.0.0 起算；版本号唯一权威来源是 `UI/AppInfo.cs` 的 `Version`（现为 "1.0.0"）。
- `docs/archive/` 归档文档与少量代码注释里出现的内部编号，仅用于追溯开发历史，不代表公开版本。

## 3. 代码改动清单
1. `UI/SiliconScope.csproj`（重命名）：`AssemblyName=SiliconScope`、`RootNamespace=SiliconScope.UI`。
2. UI 全部 `.cs`：`namespace`/`using`/完全限定名 `CpuScore.UI…` → `SiliconScope.UI…`
   （含 `ResultViewModel.cs` 中 `SiliconScope.UI.AppInfo.Version`）。
3. UI 全部 `.xaml`：`x:Class`、`clr-namespace:` 中的 `CpuScore.UI…` → `SiliconScope.UI…`。
4. `UI/AppInfo.cs`：`Version="1.0.0"`，`ProductName="SiliconScope"`。
5. `UI/MainWindow.xaml`：窗口 `Title`、侧栏品牌改 SiliconScope；侧栏版本 `V1.0.0`。
6. `UI/App.xaml.cs`：致命错误弹窗标题改 SiliconScope。
7. `UI/诊断启动.bat`：CpuScore.exe / 文案改 SiliconScope.exe。
8. `SiliconScope.sln`（重命名）：UI 项目显示名与工程路径改 SiliconScope / `UI\SiliconScope.csproj`；
   解决方案文件夹与其余工程、GUID 不变。
9. `run_all.py`：输出品牌名改 SiliconScope（调用路径不变）。
10. `UI/verify_ui.py`：工程文件名断言改 `SiliconScope.csproj`；版本断言改 1.0.0；
    新增「程序集/根命名空间为 SiliconScope」「UI 源码无旧名 CpuScore 残留」静态断言。
11. `.gitignore` / `.gitattributes`：发布目录忽略项改 `SiliconScope/`；行尾规则（*.bat CRLF）。
12. 顶层 README：根 `README.md` 为**英文**，中文移至 `README.zh-CN.md`，版本 V1.0.0。
13. `docs/交接文档/`（由带内部版本号的目录重命名）：当前版本表述统一 1.0.0，内部演进史保留。
